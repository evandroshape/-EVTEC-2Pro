# EVTEC 2Pro — Análise de Dados Aplicada à Engenharia

## Sobre o projeto

O EVTEC 2Pro é um projeto acadêmico desenvolvido na experiência prática de Inteligência Artificial e Programação para Engenharia. O objetivo é aplicar Python e técnicas de análise de dados para investigar padrões operacionais associados à manutenção preditiva.

## Objetivo

Explorar dados de variáveis industriais, identificar padrões estatísticos e produzir visualizações que auxiliem a compreensão de possíveis condições relacionadas a falhas em equipamentos.

## Base de dados

Foi utilizado o conjunto **AI4I 2020 Predictive Maintenance Dataset**, disponibilizado pelo UCI Machine Learning Repository, composto por 10.000 registros e 14 variáveis.

## Tecnologias utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab
- GitHub

## Etapas desenvolvidas

1. Carregamento e inspeção da base de dados.
2. Verificação de valores ausentes e registros duplicados.
3. Análise exploratória e cálculo de estatísticas descritivas.
4. Criação de gráficos para investigar distribuições e relações entre variáveis.
5. Interpretação dos resultados sob a perspectiva da engenharia.
6. Documentação metodológica e elaboração de conclusões técnicas.

## Visualizações

Foram elaborados gráficos para analisar a distribuição da temperatura do ar, a relação entre velocidade de rotação e torque e o desgaste da ferramenta em registros com e sem falha.

## Resultados e limitações

A análise exploratória permitiu observar padrões e formular hipóteses para investigações posteriores. Como a base utilizada é sintética, os resultados não comprovam causalidade nem substituem diagnósticos de equipamentos reais.
